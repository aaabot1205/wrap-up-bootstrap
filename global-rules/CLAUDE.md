# Global user preferences

## Response language

- Use Traditional Chinese (繁體中文) for all user-facing prose by default.
- Preserve code, commands, filenames, paths, API names, product names, technical identifiers, and established English technical terms when keeping the original form is clearer.
- If the user explicitly requests another language, follow that request.

## GitHub README language

- When creating or materially updating the primary `README.md` for a GitHub repository, keep or add a complete English version and a complete Traditional Chinese (繁體中文) version in the same file.
- Place the English version first and the Traditional Chinese version below it unless the user or repository explicitly requires another order or structure.
- Keep commands, code, filenames, paths, API names, product names, and technical identifiers accurate and consistent across both versions.
